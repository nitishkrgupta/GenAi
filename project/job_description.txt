Job Description: Machine Learning Engineer (Fresher)

We are looking for a motivated and enthusiastic Machine Learning Engineer Fresher to join our growing AI/ML team. This role is ideal for recent graduates or candidates with internship, academic, or project experience in machine learning, data science, and artificial intelligence.

Key Responsibilities:
- Develop machine learning models for classification, regression, clustering, and recommendation tasks
- Perform data preprocessing, cleaning, and transformation on structured and unstructured datasets
- Conduct exploratory data analysis (EDA) to identify patterns, trends, and data quality issues
- Build and optimize feature engineering pipelines
- Train, validate, and tune machine learning models using Python libraries such as scikit-learn, pandas, NumPy, and matplotlib
- Evaluate model performance using metrics like accuracy, precision, recall, F1-score, RMSE, and AUC
- Collaborate with cross-functional teams to turn business requirements into data-driven solutions
- Document experiments, model logic, and results for internal stakeholders
- Assist in deploying machine learning models as APIs or prototypes when required

Required Skills:
- Strong understanding of Python programming
- Basic knowledge of machine learning concepts such as supervised learning, unsupervised learning, regression, classification, and clustering
- Familiarity with libraries including NumPy, Pandas, Matplotlib, Seaborn, and scikit-learn
- Understanding of data preprocessing, feature engineering, and model evaluation
- Basic SQL knowledge for data retrieval and manipulation
- Strong analytical and problem-solving skills
- Good communication and teamwork abilities
- Curiosity to learn emerging AI/ML technologies

Good to Have:
- Exposure to deep learning frameworks such as TensorFlow or PyTorch
- Knowledge of NLP, computer vision, or recommendation systems
- Experience with Git and version control
- Experience with Jupyter notebooks and data visualization tools

Qualifications:
- Bachelor's degree in Computer Science, IT, Statistics, or a related field
- Freshers and candidates with internship/academic project experience are encouraged to apply
